# **PROJECT_NAME**

Minimal Next.js + Rakun application generated by `create-rakun-app`.

## Start

Make sure MongoDB is running, review `.env.local`, then create the initial
administrator and start Next.js:

```sh
npm run seed
npm run dev
```

- Website: `http://localhost:3000`
- Manager: `http://localhost:3000/backend`
- API health: `http://localhost:3000/api/rakun/health`

After signing in, create a Page with a slug, add a Hero module, and select that
page as the homepage in the route settings.

## Project map

- `server/content-types.ts`: minimal content model.
- `server/bootstrap.ts`: Rakun, MongoDB, login, and public route configuration.
- `app/api/rakun/[[...rakun]]/route.ts`: Rakun API.
- `app/backend/[[...slug]]/page.tsx`: manager.
- `app/[[...slug]]/page.tsx`: public page renderer.
- `modules`: React components rendered by Rakun pages.

Rakun's installed AI manuals start at
`node_modules/@rakun-kit/core/dist/docs/index.md`.
