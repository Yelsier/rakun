# **PROJECT_NAME**

Minimal Bun + Rakun application generated by `create-rakun-app`.

## Start

Make sure MongoDB is running, review `.env.local`, then create the initial
administrator and start the application:

```sh
bun run seed
bun run dev
```

- Website: `http://localhost:3000`
- Manager: `http://localhost:3000/manager`
- API health: `http://localhost:3000/api/health`

After signing in, edit the seeded Home page or create another Page with a slug.
The page route is regenerated automatically after saves.

## Project map

- `rakun.config.ts`: Bun, Rakun, MongoDB, Tailwind, manager, and route setup.
- `src/document.tsx`: server-only document layout and global stylesheet import.
- `src/styles.css`: Tailwind v4 source stylesheet.
- `src/rakun/content-types.ts`: minimal Page, Hero, and Counter model.
- `src/modules`: React components rendered by Rakun pages.
- `seed.ts`: administrator and initial Home page seed.

Tailwind is processed by Rakun through `css.plugins`, so use utility classes
directly in `src/` without a generated CSS file or separate watcher.
